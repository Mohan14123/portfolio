# Future Features & Ideas

## 1. Automated "Recent Activity" Section
- Create a new "Last Work" or "Recent Transmissions" section.
- Integrate the GitHub API to automatically fetch and display recent commits, pushes, or repository updates in real-time.
- Format the feed to look like a live terminal log or an active data stream.

## 2. Technical Blog Section
- Add a dedicated space to write long-form content, tutorials, and research findings (e.g., details on Federated Learning, MoE, etc.).
- Use MDX to allow rendering interactive components (like charts, code blocks, and math equations) directly inside the blog posts.

## 3. Interactive Terminal Easter Egg
- Build a hidden, interactive command-line interface (CLI) that users can open via a keyboard shortcut (like ``Ctrl + ` ``).
- Allow users to type commands like `whoami`, `ls projects`, or `fetch resume` to get text-based responses or unlock hidden content.

## 4. Live "System Status" Integration
- Add a widget that shows live data about what you are currently doing.
- Could integrate with Spotify (Currently Listening to), WakaTime (coding activity), or Discord (online status) to make the portfolio feel like a live, breathing system.

## 5. WebGL / 3D Interactive Background
- Implement a subtle Three.js or React Three Fiber background.
- Ideas: A rotating wireframe globe, a reactive data-grid that distorts when the mouse moves over it, or floating data particles that respond to scroll velocity.

## 6. Public Transmission Log (Guestbook)
- A simple database-backed (e.g., Prisma + PostgreSQL/MongoDB) "guestbook".
- Visitors can leave a short 100-character "transmission" or signature that gets appended to a public, scrolling list of logs.
